# koloni API

Express backend. giriş: `src/server.js`

## modüller (hedef)

| klasör | sorumluluk |
|--------|------------|
| `colony.js` | skor, oğul, arı tahmini |
| `routes/` | HTTP uçları |
| `services/` | alarm, taşıma, doğrulama |
| `middleware/` | auth, abonelik |

çalıştır: `npm run dev` (kökten)
