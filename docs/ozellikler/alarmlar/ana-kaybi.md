# Ana kaybı (queenless)

**Durum:** calisiyor (demo — Kovan 40)

Ana yok / şüpheli → koloni panik: düzensiz uğultu, bozulmuş giriş-çıkış.

## Tespit (kovan bazında)

| Sinyal | Anlam |
|--------|--------|
| Yüksek `audioRms` (≥0.52) | Panik uğultusu |
| Öğlen out ≫ in | Trafik dengesiz |
| Ana kaydı `supheli` / `yok` | Profil |
| Sağlık düşük | Destekleyici |

Tip: `queenless` · **Öncelik 1**  
Görev: **Ana kaybı şüphesi — kontrol**

## Arıcı ne yapmalı?

1. Kovanı aç — ana var mı, yumurta / genç larva var mı bak  
2. Ana yoksa: acil ana ver veya çerçeve ile ana hücre / yumurta taşı  
3. Yağma ve soğuk riskine dikkat
