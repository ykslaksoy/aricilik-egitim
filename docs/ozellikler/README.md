# koloni — uygulama özellikleri

Her özellik **ayrı Türkçe dosyada**. Kod veya sensör detayı buraya değil; kısa tanım + ne işe yarar + durum.

| Klasör | İçerik |
|--------|--------|
| `ekranlar/` | Panel / uygulama ekranları |
| `skorlar/` | Koloni, sağlık, oğul, arı tahmini |
| `kovan-kaydi/` | İşletme, ana, baba, ırk, düzen |
| `sensorler/` | Tartı, IR, mic, titreşim… |
| `alarmlar/` | Oğul, tartı, pil, densizlik… |
| `kalibrasyon/` | Tare, öğlen, petek silkme, yapay zeka |
| `gezginci/` | Arılık, taşıma, yerleşme |
| `abonelik/` | Paketler, kilitler |
| `bildirimler/` | Push, SMS, kanallar |
| `donanim/` | paket standart/kamera, kovan kartı, geçit, WiFi ağ kutusu |
