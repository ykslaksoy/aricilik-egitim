# Dil / i18n

Varsayılan dil: **Türkçe (`tr`)**.

## Yapı

```
packages/shared/i18n/
  index.js   — setLocale / t / alertTypeTr …
  tr.js      — Türkçe (aktif)
  en.js      — İngilizce iskelet (hazır, henüz UI’da seçilmiyor)
```

## Yeni dil eklemek

1. `packages/shared/i18n/<kod>.js` — `tr.js` ile aynı anahtarlar  
2. `index.js` içinde `catalogs`’a ekle  
3. Panel: `PanelLabels.setLocale('<kod>')` (veya `?lang=` / kullanıcı tercihi)  
4. API: `KOLONI_LANG=<kod>` veya işletme ayarı

Kod anahtarları (`swarm_risk`, `offline`) değişmez; sadece çeviri dosyası büyür.
